# Expo HAS CHANGED

Read the exact versioned docs at https://docs.expo.dev/versions/v54.0.0/ before writing any code.

Este projeto está fixado no **SDK 54** de propósito: é o SDK suportado pelo Expo Go
instalado no aparelho de teste (Expo Go 54.0.8, Android).

Antes de subir de SDK, confirme qual versão do Expo Go o aparelho realmente tem —
a Play Store pode anunciar "atualizado" e ainda assim entregar um cliente antigo.
Para descobrir sem adivinhar, aponte o Expo Go para um servidor HTTP qualquer e leia
o cabeçalho `exponent-sdk-version` da requisição.
